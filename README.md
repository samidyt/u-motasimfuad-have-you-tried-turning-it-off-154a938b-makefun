A [make.fun](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty entry: one funny line, under 200 characters, that a hopeless tech support agent says to a desperate customer.

## The entry

`main.py` writes a single line — the agent's classic empathy script ("I completely understand", "rest assured") collapsing into the admission that everything he can possibly do is nothing, but he did all of it — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It validates the line against the gate (one line, 1–199 characters, non-blank) before writing, then prints the line and its character count.
